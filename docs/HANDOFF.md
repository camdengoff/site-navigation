# How to change the navigation links

*This page is for whoever looks after the website. You don't need to know how to
code, and you don't need to open or edit any code.*

The row of links near the top of pages like **Watch Online** is ordinary text on
the page. You edit it the same way you'd edit any other text in Squarespace.
When you save, it turns into the finished bar.

---

## Changing, adding, or removing a link

1. In Squarespace, click **Edit** on the page.
2. You'll see a dashed box that says *Navigation bar*, and below it the label
   and a bulleted list of links. That's the bar.
3. Edit the list like any other text:
   - **Change the wording** — click into it and type.
   - **Change where a link goes** — select the link text and click the link
     button, then pick a page from the list.
   - **Add a link** — put your cursor at the end of a line, press Enter, type
     the new name, and link it.
   - **Remove a link** — delete that line.
   - **Reorder** — cut and paste the line, or retype them in the order you want.
4. Click **Save**.
5. Open the live page and refresh.

**The bar won't look finished while you're editing.** Squarespace turns off the
code that builds it whenever you're in the editor, so you'll see plain text and a
bulleted list. That's normal and it's not broken — save and look at the live
page to see the real thing.

---

## Turning the bar on for another page

1. Open the page and click **Edit**.
2. Click **Add Section**, then **Saved**.
3. Pick **Page navigation**.
4. Drag it to just under the top of the page if it isn't already there.
5. Edit the label and links as above, then **Save**.

## Turning the bar off for a page

Edit the page, hover over the navigation section, and delete the section. The
bar is off for that page. Every other page is unaffected.

Pages are **off by default** — a page only shows the bar if someone added the
section to it.

---

## Good to know

- **The underline** appears automatically on whichever link matches the page the
  visitor is on. You don't set it.
- **The label** uses whichever Heading style you set it to. Change that heading's
  font in Squarespace's style settings and the bar follows.
- **Colors and fonts** are set once for the whole site, not per page, so every
  bar matches. Changing them is a small job for whoever set the site up.
- **On phones**, the bar becomes one line — the label on the left, an arrow on
  the right that opens the links.
- **Don't delete the dashed box.** That's the marker that tells the site to build
  the bar. Without it you'll just have a bulleted list.
- **If the bar shows as a plain list of links on the live site**, the marker box
  was deleted or the section was pasted in incompletely. Add the saved section
  again from **Add Section → Saved**.

## Adding a page to the menu that doesn't exist yet

Create and publish the page first, then come back and add the link. Squarespace's
link picker only lists pages that already exist.
