Page Navigation

A small, tidy navigation bar for section pages. The bar above is a live example — narrow your browser window to see how it behaves on a phone.

Open the builder →

The builder writes the code for you. You never have to edit a file.

What it does differently

In a tight space the bar stays one line tall — your label on the left, an arrow on the right that opens the links. If you'd rather keep every link visible, you can switch it to a row that swipes sideways instead — both are options in the builder, and either way it's one block to maintain instead of a desktop version plus a separate mobile menu.

Changing the links later

Open the builder, paste in the code that's already on your page, make your changes, and copy the new code back. Full instructions are in the README.
