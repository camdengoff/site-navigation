Links

One row per link. Use a short path like /worship for pages on your own site, or a full https:// address for anywhere else.

Appearance

With site styles, the label and links are real heading and paragraph text, so they follow the fonts you set in Squarespace → Website → Site styles → Fonts. Change them there and this follows.

Click a square to pick a color, or type a hex code like #1a56db. Text sets the label and the links to the same color; Link color on hover is the only one that can differ.

Heads up: this text color is hard to read on this background. Visitors with low vision may not be able to read the links.

The bar's background always reaches the edges of the page on its own, even from inside a narrower Code Block. Like sticky, that can fail if the section around the bar clips its own content (Squarespace section wrappers sometimes set overflow: hidden) — check the real page.
